# 실험 기록

StyleForge 개발 과정에서 수행한 실험과 그 결과를 기록한다.
각 실험은 **가설 → 설정 → 결과 → 해석 → 결정** 순으로 작성한다.

> 작성 원칙
> - 실패한 실험도 기록한다. 실패 원인이 다음 실험의 근거가 된다.
> - 수치 없는 "좋아 보인다"는 쓰지 않는다. 판단 근거를 함께 남긴다.
> - 결정 사항은 `CLAUDE.md` 또는 `docs/dataset-aihub-minhwa.md`에 반영하고, 여기에 반영 여부를 적는다.

## E0. 데이터셋 스키마 실측 검증

**상태:** ✅ 완료
**대상:** AI 허브 「한국 전통 민화 제작 데이터」 (2025 구축)

### 배경
공식 데이터 설명서(HWP)에 라벨 JSON 스키마와 화목 분류 체계가 명시되어 있었다.
파서를 설계하기 전에 명세와 실제 데이터가 일치하는지 확인했다.

### 방법
1. `tree`로 실제 디렉터리 구조 확인
2. 화조도(HJ) 라벨 JSON 745건을 순회하며 필드값 분포 집계
3. 샘플 JSON 1건(`HJ_0001.json`)의 전체 구조를 육안 확인

### 결과 — 명세와 실제의 불일치 3건

| # | 항목 | 설명서 명세 | 실제 데이터 | 영향 |
|---|---|---|---|---|
| 1 | 화풍 필드명 | `painting_style` | **`painting_type`** | 명세대로 파싱 시 745건 전부 `None` 반환 |
| 2 | `drawing_type` 값 도메인 | 채색 / 수묵 / 수묵담채 (3종) | **12종 이상**, 복합값 존재 (`채색, 혁필` 등) | 완전 일치 매칭 필요. 부분 매칭 시 21건 오염 |
| 3 | `info` 블록 | 명세에 없음 | **존재** (version, copyright 등) | 저작권 문구 확보 — 이용 조건 근거로 활용 |

추가 확인 사항:
- **순번에 결번이 있다.** (예: `IM_0029` 부재) → 번호 순회 방식 금지, 디렉터리 목록 읽기 필수
- **`object_file_name`은 배열이 아닌 쉼표 구분 문자열** (`"HJ_0001_1, HJ_0001_2"`)
- **종횡비가 극단적이다.** 실측 예 317×1080 (약 1:3.4). 족자·병풍 형태가 다수

### 화조도(HJ) 실측 분포

`Training\01.원천데이터\TS_기본데이터_09.화조도` = **745장** (Validation 184장, 8:2 분할)

`drawing_type`:

| 값 | 장수 |
|---|---:|
| 채색 | 597 |
| 담채 | 32 |
| 낙화 | 29 |
| 수묵 | 18 |
| 기타 | 16 |
| 수묵, 담채 | 15 |
| 판화 | 15 |
| 채색, 혁필 | 13 |
| 판화, 채색 | 6 |
| 채색, 수묵 | 2 |
| 담채, 기타 / 기타, 채색 | 각 1 |

`채색` 597장 내 `painting_type`:

| 값 | 장수 |
|---|---:|
| 일필+공필 | 411 |
| 공필 | 160 |
| 일필 | 26 |

### 해석
공식 설명서를 그대로 신뢰해 파서를 작성했다면 화풍 필터가 조용히 실패해
전체 데이터가 무필터로 학습에 들어갔을 것이다. 필드가 `None`을 반환해도 예외가 발생하지 않으므로
학습 결과가 나빠진 뒤에야 원인을 역추적하게 된다.

종횡비 문제도 마찬가지다. 512×512 정사각 리사이즈를 기본값으로 두었다면
세로로 긴 족자 그림이 뭉개진 채 학습되어, 원인 불명의 품질 저하로 이어졌을 것이다.

### 결정
1. **파서는 실제 JSON을 기준으로 작성한다.** 필드 접근은 `.get()`, 값이 없으면 경고 후 항목 제외
2. **확정 학습 필터:** `HJ` + `drawing_type=채색` + `painting_type=일필+공필` → **411장**
   - 복합값 존재로 **완전 일치 매칭만 허용**
   - 대안: `painting_type=공필` 160장 (E3에서 비교)
3. **`enable_bucket=true` 필수** — `bucket_reso_steps=64`, `min_bucket_reso=256`, `max_bucket_reso=1024`
4. `scan.py`의 종횡비 이상치 기준을 1:4까지 정상으로 완화
5. 서브셋 선별은 파일명 파싱이 아닌 **디렉터리 선택**으로 처리 (폴더가 이미 화목별로 분리됨)

**반영:** `docs/dataset-aihub-minhwa.md` 2·3·3-1·3-2·5장, `CLAUDE.md` 2-(3)·3장

## E4. style transfer 파라미터 스윕

**상태:** ⬜ 예정

### 가설
img2img에서 `denoise`와 `lora_weight`는 트레이드오프 관계에 있다.
denoise가 낮으면 원본은 보존되나 화풍이 약하고, 높으면 화풍은 강하나 원본이 소실된다.
ControlNet으로 구조를 고정하면 **더 높은 denoise에서도 원본 보존이 가능**할 것이다.

### 설정
`styleforge sweep`으로 자동 탐색:
- `denoise`: 0.4 / 0.55 / 0.7 / 0.85
- `lora_weight`: 0.4 / 0.6 / 0.8 / 1.0
- `controlnet_strength`: 0.0(대조군) / 0.6

입력 이미지: 풍경 사진, 인물 사진, 정물 사진 각 1장

### 평가 지표
- **스타일 적용도:** 생성 이미지 ↔ 학습 데이터셋의 CLIP 유사도
- **원본 보존도:** 생성 이미지 ↔ 입력 이미지의 CLIP 유사도
- 두 값의 산점도에서 파레토 프론트를 확인하고 `--strength` 매핑 곡선을 도출

**데이터셋:** AI 허브 「한국 전통 민화 제작 데이터」 (2025년 구축)
**구축기관:** 에이치씨아이플러스(주) / 검수: 제주대학교 산학협력단
**원본 소장처:** 가회민화박물관(65.15%), 국립민속박물관(10.21%), 국립중앙박물관(7.20%) 등 50개 기관

라벨 JSON의 `info.copyright` 필드에 명시된 조건:
> 에이치씨아이플러스 컨소시엄. AI 학습 목적 외에 저작권자의 동의 없이 상업적 목적으로 이용할 수 없습니다.

### 준수 사항
- 본 프로젝트는 **개인 포트폴리오 목적의 AI 학습 파이프라인 개발** 용도로만 사용한다.
- 상업적 이용은 수행기관과 별도 협의가 필요하므로 시도하지 않는다.
- 원본 이미지 · 라벨 JSON · CSV를 저장소에 커밋하거나 재배포하지 않는다.
- 학습된 `.safetensors` 가중치를 공개 저장소에 업로드하지 않는다.
- 공개 범위는 **코드 · 생성 결과 이미지 · 문서**로 한정한다.
