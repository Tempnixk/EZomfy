### 로컬 설치 경로 (개발 환경 기준)

```
D:\ComfyUI-Easy-Install\ComfyUI-Easy-Install\Data_MinHwa
```

**코드에 이 경로를 직접 기입하지 않는다.** `.env`의 `DATASET_ROOT`로 주입하고
`config.py`를 통해 읽는다.

```dotenv

```

> **참고:** 현재 데이터가 ComfyUI 설치 디렉터리 하위에 있다.
> ComfyUI를 재설치·업데이트할 때 함께 삭제될 위험이 있으므로,
> 여유가 되면 `D:\datasets\` 등 독립 경로로 옮기고 `.env`만 수정하는 편이 안전하다.

### 실제 디렉터리 구조

```
{DATASET_ROOT}\13.한국 전통 민화 제작 데이터\3.개방데이터\1.데이터\
├─ Other\메타데이터\{NN.화목명}\                      # CSV (메타데이터)
├─ Training\
│  ├─ 01.원천데이터\TS_기본데이터_{NN.화목명}\        # JPG ★ 학습 대상
│  │                TS_상세묘사데이터_{NN.화목명}\    # JPG (제외)
│  └─ 02.라벨링데이터\TL_기본데이터_{NN.화목명}\      # JSON ★ 캡션 소스
│                     TL_상세묘사데이터_{NN.화목명}\  # JSON (제외)
└─ Validation\
   ├─ 01.원천데이터\VS_기본데이터_{NN.화목명}\        # JPG ★ FID 기준셋
   │                VS_상세묘사데이터_{NN.화목명}\
   └─ 02.라벨링데이터\VL_기본데이터_{NN.화목명}\      # JSON
                      VL_상세묘사데이터_{NN.화목명}\
```

**접두어 규칙**

| 접두어 | 의미 |
|---|---|
| `TS_` | Training / 원천(Source) — 이미지 |
| `TL_` | Training / 라벨(Label) — JSON |
| `VS_` | Validation / 원천 — 이미지 |
| `VL_` | Validation / 라벨 — JSON |

### 이 구조에서 도출되는 구현 규칙

**(1) 화목 선별 = 디렉터리 선택.** 파일명 접두어를 파싱할 필요가 없다.
화목 폴더가 `{2자리 번호}.{화목명}` 형식이고, **번호 순서가 화목 코드 순서와 일치**한다
(아래 코드표의 `폴더` 열 참조). `--filter HJ` → `09.화조도` 폴더로 해석한다.

**(2) 상세묘사 데이터 제외 = 해당 폴더를 읽지 않는 것.**
`*_기본데이터_*` 폴더만 대상으로 하고 `*_상세묘사데이터_*`는 기본적으로 건너뛴다.

**(3) 이미지 ↔ 라벨 페어링은 경로 치환으로 처리한다.**
```
TS_기본데이터_09.화조도\HJ_0123.jpg
  → 01.원천데이터 → 02.라벨링데이터,  TS_ → TL_
TL_기본데이터_09.화조도\HJ_0123.json
```
치환 후 파일이 없는 경우가 있을 수 있으므로 **페어링 실패 항목은 경고 후 제외**한다.

**(4) Training / Validation 분할이 이미 되어 있다. 재분할하지 않는다.**
- 학습에는 `Training\01.원천데이터\TS_기본데이터_*`만 사용한다.
- **`Validation\01.원천데이터\VS_기본데이터_*`는 FID 계산의 실제 이미지 기준셋으로 사용한다.**
  FID는 실제 이미지 분포와 생성 이미지 분포를 비교하는 지표이므로 레퍼런스 실사 세트가 필요한데,
  학습에 쓰지 않은 동일 화목 이미지가 이미 분리되어 있어 그대로 활용할 수 있다.

**(5) 순번은 연속이 아니다.** 실측 확인 결과 결번이 존재한다(예: `IM_0029` 없음).
번호를 순회하며 경로를 생성하는 방식으로 구현하지 말고,
**반드시 실제 디렉터리 목록을 읽어서 처리한다.**

### 파일명 규칙

```
기본 데이터    : {화목코드 2자리}_{순번 4자리}.jpg      예) HJ_0001.jpg
상세묘사 데이터: {화목코드 2자리}_{순번 4자리}_{n}.jpg  예) HJ_0001_1.jpg
라벨           : 동일 규칙의 .json
메타데이터     : 동일 규칙의 .csv
```

**따라서 장르 선별은 캡션 텍스트를 파싱할 필요 없이 파일명 접두어 2자리로 처리한다.**
상세묘사 데이터는 `_숫자` 접미사 유무로 구분하며, **기본 학습에서는 제외한다**
(원본의 부분 확대 이미지이므로 중복 학습으로 스타일이 왜곡될 수 있음).

## 3-2. 종횡비 주의 (★ 학습 설정에 직결)

실측 예: `img_width` 317 × `img_height` 1080 (약 1:3.4).
족자·병풍 형태가 많아 **극단적 세로 비율이 정상값**이다.

- **kohya `enable_bucket=true` 필수.** 정사각 강제 리사이즈 시 그림이 왜곡되고,
  센터 크롭 시 구도가 잘려 화풍 학습이 실패한다.
- `bucket_reso_steps=64`, `min_bucket_reso=256`, `max_bucket_reso=1024` 권장.
- `scan.py`의 "종횡비 이상치" 검증은 **이 데이터셋에 한해 기준을 완화한다.**
  1:4 수준까지는 정상으로 간주하고, 그 이상만 경고한다.

## 4. 캡션 활용 전략 (구현 지침)

### 반드시 영문 캡션(`caption_eng`)을 사용한다
SD 1.5의 텍스트 인코더(CLIP ViT-L/14)는 **영어 전용**이다.
한글 캡션을 그대로 넣으면 토크나이저가 의미를 잡지 못해 학습이 실패한다.
`caption_kor`는 사람이 데이터를 검토할 때만 참고한다.

### 필드별 처리 방침

| 필드 | 학습 캡션에 포함 | 처리 |
|---|---|---|
| `keyword_eng` | ✅ 기반으로 사용 | 이미 쉼표 구분 형태 → kohya 태그로 거의 그대로 사용 가능 |
| `composition_eng` | ✅ 축약 후 포함 | **내용(무엇이 그려졌는가)** 은 캡션에 남겨야 스타일이 내용에 오염되지 않음 |
| `overview_eng` | ⚠️ 부분 | 화목 분류 언급은 스타일 정보이므로 제거 |
| `production_eng` | ❌ 제거 | 제작 기법 = 스타일. LoRA가 흡수해야 할 대상 |
| `symbolism_eng` | ❌ 제거 | 상징 해석은 시각 정보가 아님. 노이즈 |
| `normal_eng` | ❌ 미사용 | 위 필드들의 통합본이라 중복 |
| `object*_eng` | ❌ 미사용 | 상세묘사 이미지용 |

### 스타일 토큰 제거 대상
아래 표현은 캡션에서 제거하고 트리거 워드가 대신 담당하게 한다.
`traditional Korean folk painting`, `minhwa`, 화목명(`floral painting`, `bird-and-flower painting` 등),
`ink`, `color on hanji`, `Joseon`, 기법·재료 관련 표현.

### 최종 캡션 형태

## 5. 구조화 필드를 활용한 추가 필터링

`folkpainting`의 아래 필드로 학습 데이터 동질성을 높인다.
화목 코드만으로는 기법·화풍이 섞이므로 2차 필터를 반드시 적용한다.

| 필드 | 비고 | 활용 |
|---|---|---|
| `painting_type` | ★ 명세의 `painting_style` 아님 | 화풍 동질성 확보 1순위 |
| `drawing_type` | 복합값 존재, 완전 일치 매칭 필수 | 채색 선별 시 색감 일관성 상승 |
| `ground_material` | 한지 71.61% / 수입지 13.52% / 견 12.17% | 바탕 질감 통일 |
| `sources` | 가회민화박물관 65.15% | 촬영 조건 통일 효과 |

**화조도 확정 조합:** `subject_type_id=HJ` + `drawing_type=채색` + `painting_type=일필+공필` → 411장
(실측 분포는 3-1절 참조)

## 6. 이용 조건 준수 사항

- 데이터 권리는 구축 수행기관 및 한국지능정보사회진흥원에 있다.
- 본 프로젝트는 **개인 포트폴리오 목적의 AI 학습 파이프라인 개발** 용도로만 사용한다.
- 판매 등 상업적 이용은 수행기관과 별도 협의가 필요하므로 시도하지 않는다.
- **원본 이미지·라벨 JSON·CSV를 저장소에 커밋하거나 재배포하지 않는다.**
- **학습된 `.safetensors` 가중치를 공개 저장소에 업로드하지 않는다.**
- 공개 범위는 **코드 · 생성 결과 이미지 · 문서**로 한정한다.
- README에 출처와 이용 조건 준수 내역을 명시한다.
